Origin

Interpretable detection, localization, and explanation of LLM-generated text.

Eric Xu·August 2026

Python·TypeScript·Research prototype

GitHub Protocol

00Abstract

Origin asks whether a text was written by a person, a language model, or both. Instead of one opaque score it labels documents Human, AI or Mixed, localizes the verdict to sentences, and shows the evidence: perplexity, surprisal, burstiness, lexical and stylistic features.

One analysis engine sits behind a FastAPI API, a React UI and a CLI, with an evaluation framework for ablations and held-out-family tests.

01Questions

  • Human, AI, or mixed?
  • Which sentences?
  • What signals support the call?
  • Does it hold up on model families it never saw?
  • Does it survive paraphrasing, temperature changes, and mixing?
  • Do neural detectors learn the same signals as the classical features?

02How it works

Predictability and burstiness

A language model gives every token a probability. Surprisal is how unexpected a token is; perplexity summarizes a passage. Model-sampled text is unusually predictable under a model, and more uniform: people mix long sentences with fragments and predictable stretches with surprising ones. Origin measures that burstiness over sentence perplexities and lengths.

Two detectors, one of them fully inspectable

The classical detector is a calibrated logistic regression over about 40 interpretable features, exported as JSON with its feature importances. The neural one is a fine-tuned transformer sentence classifier with a documented rule for turning sentence probabilities into a document verdict. Ablations measure what each signal family adds.

More data helps in-distribution, not transfer

Tripling the corpus improved in-distribution detection, the weakest families and localization. Transfer to GPT-4 stayed near 0.80 either way, so the linear model is the limit there, not the data. Perplexity alone reached 0.61 on GPT-4 in a pilot; the ensemble of signals is what transfers.

Paraphrase still wins

A paraphrase attack drops detection to chance, which matches the literature.

04Limitations

A signal for review, not a verdict

Detection is statistical inference, never proof. Short texts carry little signal, editing and paraphrasing move text across the boundary in both directions, and false positives happen. Every result carries a disclaimer.

05Reproducibility

Lockfiles are pinned. Every stochastic step is seeded, and a document and its paraphrase never straddle a split. Experiment outputs embed their config, seed and git commit. Tests run offline against 200 KiB model fixtures. The bundled sample corpus is synthetic and only validates the pipeline; real evaluation means importing a real corpus and an HF scorer.
