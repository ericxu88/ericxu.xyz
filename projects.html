  1. 012026

    SREGym

    Every seed builds a small production stack on disk, quietly breaks it, and pages an LLM agent about the outage. A deterministic verifier checks whether the agent actually fixed the root cause, so nothing here is graded by another model.

    GitHub Env Hub
  2. 022026

    GUARD

    Models degrade quietly, and most ways of noticing cost you latency. GUARD watches a serving PyTorch model for drift without labels and without moving anything off the GPU, running its detectors on a spare CUDA stream that uses whatever inference leaves idle.

    GitHub
  3. 032026

    mimir

    You tweak a prompt, the score goes up two points, and you have no idea whether that was real. mimir makes you write the hypothesis down first, then runs the paired bootstrap and tells you if the difference survives the noise. It audits the LLM judge too.

    GitHub
  4. 042026

    Origin

    Works out whether a piece of writing came from a person, a model, or both, and points at the specific sentences behind the call. Instead of one opaque score you get the evidence: perplexity, burstiness, and about forty other features you can actually read.

    GitHub
  5. 052025-26

    Relay

    A control plane for agents that have already started doing something. Relay catches the action while it is still in motion, steps in before it lands, and cleans up after the ones that get through.

    Site

    In Silico Identification and In Vitro Validation of Repurposed Compounds Targeting the RSV Polymerase

    Xu, Park, Calderon, Cao, Liang. Microorganisms 11(6), 2023. Docked 6,554 clinical-stage compounds against the RSV polymerase, then took the best of them to the bench: Micafungin, an antifungal already on the market, out-bound the existing inhibitors and held up in an in vitro transcription assay.
